# idai102_2605392_Herit-patel
My project, AgroNova – Smart Farming Assistant, is a Generative AI-powered web application designed to help farmers make better agricultural decisions. I have used Python as the main programming language and Streamlit to develop an interactive and user-friendly web interface. I have integrated the Google Gemini API using the Google Gen AI SDK to generate intelligent, AI-powered farming suggestions. The application uses prompt engineering to provide relevant responses based on the farmer's location, soil type, farming questions and preferred language. It offers guidance on crop recommendations, pest management, soil fertility, fertilizers and smart irrigation. I have also used Python functions, conditional statements, input fields, dropdown menus and error handling to make the application interactive and easy to use. The main aim of AgroNova is to support sustainable agriculture, save natural resources, improve farming decisions and make modern AI technology accessible to farmers.
